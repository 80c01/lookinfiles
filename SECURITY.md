# Security policy

LookinFiles opens files from anywhere: archives, PDFs, mail, office documents,
binaries, web pages. A file that crashes the preview, runs code, or reads or
writes outside what you opened is a security issue.

## Supported versions

Fixes go into the latest release only.

## Reporting a vulnerability

Do not open a public issue. Report it privately through
[GitHub security advisories](https://github.com/80c01/lookinfiles/security/advisories/new).

Please include the version (`lookinfiles --version`), your system, the steps
to reproduce and, if you can, a sample file. You will get an answer within a
week, and credit in the release notes unless you prefer otherwise.
